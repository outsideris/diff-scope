### 20:10 - diff 렌더러를 @pierre/diffs로 교체

- Summary: diff 렌더링 라이브러리를 `@git-diff-view/react` + `@git-diff-view/shiki`에서 `@pierre/diffs` 1.3.5로 교체했다.
- Context: "지금 쓰는 diff 렌더링 라이브러리와 https://diffs.com/ 를 비교해 달라"는 요청에서 시작했다. diffs.com은 `@pierre/diffs`(Pierre가 자사 git 플랫폼 diff 엔진을 공개한 Apache-2.0 라이브러리)였다. 비교 결과 유지보수 규모(컨트리뷰터 26명 vs 1인), 가상화 지원, 번들 무게, 그리고 git-diff-view의 2,000줄 하이라이팅 무음 중단 문제에서 pierre가 우위라 교체하기로 했다. 근거는 `docs/DESIGN.md`의 "diff 렌더링 교체" 항목에 정리했다.
- Changes:
  - `src/renderer/src/components/DiffPane.tsx`: `DiffView` → `<PatchDiff patch={file.raw} options={...}>`. Shiki highlighter 어댑터(`useHighlighter`, 23줄)와 `useDarkMode` 훅 제거 — pierre는 Shiki를 내장하고 `themeType` 기본값 `"system"`이 OS 다크 모드를 직접 따라간다. 파일 헤더는 앱이 계속 그리므로 `disableFileHeader: true`.
  - `src/renderer/src/main.tsx`: `@git-diff-view/react/styles/diff-view-pure.css` import 삭제 — pierre는 CSS 파일을 배포하지 않는다.
  - `src/renderer/src/styles.css`: `:root`에 `--diffs-font-family/-size/-line-height/-tab-size` 추가. pierre는 shadow DOM 안에 렌더링해서 페이지 셀렉터가 닿지 않고, 커스텀 프로퍼티만 상속으로 넘어간다.
  - `src/renderer/src/lib/lang.ts` 삭제: pierre가 파일명으로 언어를 추론하므로 Shiki 언어 ID 맵이 필요 없어졌다.
  - `package.json`: `@pierre/diffs` 추가, `@git-diff-view/react`·`@git-diff-view/shiki` 제거.
- Tests: `npm test` 98개 통과(21 파일). `npm run typecheck`, `npm run lint`, `npm run format:check`, `npm run build` 모두 통과.
- Tests Added: 없음. 이번 변경은 렌더러 컴포넌트의 표시 계층이고, 순수 로직(`parseDiff.ts`)은 그대로라 기존 테스트가 그대로 검증한다.
- Quality Gate: 필수 항목 전부 확인(테스트/빌드/린트/포매팅/타입체크/앱 구동). 앱 구동은 CDP로 검증했다 — Working 뷰에서 파일 선택 시 `<diffs-container>` shadow DOM에 라인·문법 강조·word-level 강조·"44 unmodified lines" 구분자까지 렌더링되고, Unified/Split 전환이 동작하며, History 뷰에서 3파일 커밋이 각각 마운트되는 것을 스크린샷으로 확인했다. shadow DOM 안 `<pre>`의 computed style이 `12px` / `ui-monospace` / `18px`로 나와 CSS 커스텀 프로퍼티 상속도 확인했다.
